Anomicon mobile processing: a reviewed static observation pose was baked from
the upstream rig animations (049_Idle2, 106_Idle, 173_Pose1 and 939_Idle), runtime
animation tracks were removed, embedded textures were constrained to 1024px,
unused data was cleaned, and an AnomiconInteractivePivot node was added for the
mobile viewer. The shipped files are visual reconstructions, not official SCP
Foundation models.

The SCP-131-A, SCP-3199, SCP-650, SCP-079, SCP-178 and SCP-686 entries are on-demand rows.
Their immutable upstream GLBs are downloaded over HTTPS, checked against the manifest byte length
and SHA-256, and retained only in the app-private archive cache. The viewer
samples a reviewed named pose when one is configured; SCP-650 uses its authored
neutral pose and keeps all runtime animation tracks disabled. Deleting an entry
removes only that private cache object.

The viewer presents only the bottle exterior. It must not be interpreted as
safe handling guidance for the infectious contents described by the article.

Delivery policy: only reviewed classic seed objects are bundled. Other reviewed
objects remain on demand and must pass the same fixed-source, license,
attribution, size and SHA-256 review before they are added to the manifest.
SCP-096 is not listed yet because no fixed redistributable source has passed
that review; no unavailable model entry is exposed in the article menu.

SCP-173 is the NEO/version-2 redesign asset. The SCP Foundation licensing
guide still contains additional guidance for the former Untitled 2004
sculpture likeness; review that guide before any commercial distribution:
https://scp-foundation.net/licensing-guide
