Anomicon mobile processing: animations removed, embedded textures constrained
to 1024px, unused data cleaned, and an AnomiconInteractivePivot node added for
the mobile viewer. The shipped files are visual reconstructions, not official
SCP Foundation models.

SCP-173 is the NEO/version-2 redesign asset. The SCP Foundation licensing
guide still contains additional guidance for the former Untitled 2004
sculpture likeness; review that guide before any commercial distribution:
https://scp-foundation.net/licensing-guide
